# Frontend Documentation

## Обзор проекта

Это фронтенд-часть игры в жанре карточной дуэли в стилистике **тёмного фэнтези / подземелья**. Игроки собирают колоды артефактов, сражаются друг с другом в пошаговых битвах, используют заклинания и прокачивают свои коллекции.

---

| Технология | Назначение |

| **React** | Основной фреймворк |
| **TypeScript** | Типизация |
| **Redux Toolkit** | Управление состоянием |

| **CSS Modules** | Стилизация |

```

├── app/ # Store и глобальная конфигурация
```

## Основные игровые механики

### 1. Аутентификация
- Регистрация / Вход
- Инвайт-коды для доступа
- Восстановление сессии

### 2. Лобби и матчмейкинг
- Создание публичных/приватных лобби
- Поиск по названию
- Присоединение по коду
- Приглашение друзей
- Настройка таймеров

### 3. Драфт (выбор карт)
- Игрок выбирает 7 артефактов из своей колоды из 14 карт
- Драфт синхронный (выбор одновременно с соперником)
- Можно смотреть колоду соперника

### 4. Битва
- **Раундовая система**: фаза расстановки → ходы игроков → окончание раунда
- **Кубики артефактов**: каждый ход игрок использует грань кубика
- **Ресурсы**: Ярость, Ловкость, Мана (свет, тьма, разрушение)
- **Заклинания**: доступны из книги заклинаний
- **Линии**: передняя (защищает заднюю) и задняя
- **Эффекты и состояния**: оглушение, оцепенение, сон и др.

### 5. Коллекция и колоды
- Сбор карт за игровую валюту
- Формирование 3 колод по 14 карт
- Редактирование колод (замена карт)
- Фильтрация по типам артефактов

### 6. Профиль и социализация
- Добавление друзей по коду дружбы
- Статистика (победы/поражения, серии)
- Просмотр профилей других игроков

### 7. Админ-панель
- Управление пользователями (выдача/снятие прав)
- Просмотр жалоб
- Генерация и управление инвайт-кодами

## Стилизация (Design System)

### Цветовая палитра

| Назначение | Цвет |
|------------|------|
| Основной фон | `#1a1518`, `#2a2220` |
| Текст основной | `#e8d9c0` |
| Текст заголовков | `#ffd7a5` |
| Акценты, золото | `#aa7840`, `#d49c5c` |
| Рамки, металл | `#5d4a36`, `#8b6f4c` |
| Успех / Здоровье | `#3d7a63`, `#a8d5c5` |
| Ошибка / Урон | `#8b4c4c`, `#d5a8a8` |

### Шрифты
- **Forum** — основной, для заголовков и атмосферных элементов
- **Open Sans** — для числовых значений и технических элементов

## Адаптивность

Проект поддерживает следующие разрешения:

| Категория | Разрешение | Особенности |
|-----------|------------|-------------|
| **Крупные мониторы** | 1750px+ | Увеличенные карточки, отступы, шрифты |
| **Десктоп** | 1400px - 1749px | Стандартные размеры |
| **Ноутбук** | 1024px - 1399px | Уменьшенные элементы |
